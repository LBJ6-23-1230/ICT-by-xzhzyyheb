# 华为 ICT 大赛创新赛道改造入口

本目录是当前项目的赛事改造真源。自 2026-10-23 起，项目以用户提供的华为 ICT
大赛创新赛题截图为需求基线，目标赛题为：

> 赛题 2：基于华为云 AgentArts 智能体开发平台的 Agent 设计和应用。

旧赛事专用的规程、提交模板、答辩稿、视频稿和提交脚本已从当前工作区清理；可复用的
源码、技术记录、自动化测试与运行证据继续作为迁移基线，但不代表华为 ICT 大赛已完成。

## 当前结论

项目已有可复用的学习场景、HarmonyOS Demo、五角色 Agent 逻辑、工具权限、知识库、
确定性判分、计划重排、Trace、接口契约和测试体系；目前的核心缺口是这些能力尚未在
AgentArts 上完成真实构建、编排、调试、评估与部署。因此本轮不是简单换文案或换云主机，
而是把“智能体控制面”迁到 AgentArts，并把既有后端能力整理为可被 AgentArts 调用的
MCP/服务工具。
