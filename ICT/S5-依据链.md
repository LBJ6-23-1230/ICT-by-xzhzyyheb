# S5 依据链：可点开的数字与引用

> 对应赛题"创新性 60%"：市面上的学习应用都在给建议，**很少把建议的依据摆出来**。
> 这一节把"模型只判断、不算数"从口号变成界面上可点开的东西。

## 一、界面：依据挂在回答下方，不单独占一块

> 第一版把"学情标签 + 引用列表"放在右侧证据面板，看起来像开发者调试台。
> 用户要看的是"这句话凭什么"，所以改成**每条回答自带依据入口**。

### 1. 回答下方的一行入口

```text
今晚已安排 2 个任务，共 60 分钟…
────────────────────────────────
[🧮 学情依据]  [📚 资料依据 · 1]
```

点「📚 资料依据」就地展开：

```text
二叉树讲义.pdf · 第3章 3.2 二叉树遍历基础
后序遍历的顺序是左右根，先访问左子树…
```

再点某一条 → 弹窗：文件、章节、**片段哈希**、相似度、正文。

**片段哈希**是重点：由切片文本算出，可与原文核对——"引用"不是模型编的一句话。

### 2. 学情入口收在顶栏

顶栏一个 `学情 · 3 个知识点`，点开才看：

```text
二叉树遍历基础  42  🧮计算
图算法          55  🧮计算
哈希冲突        63  🧮计算
画像版本 v3
换算规则  R1：满分 → +29 …
          R2：<60 → -4（含错题默认 0 分）
```

**为什么不常驻**：学情是"背景信息"，不是每次对话都要看的东西。
常驻会把主界面变成仪表盘，反而削弱对话。

### 3. 没有依据时如实说"没有"

检索为空时入口直接显示「📚 无资料依据」，展开写「本次回答没有引用资料」。

不允许出现"看起来像引用、实际没来源"的内容。这条和 S4 里 `create_grounded_exercise`
的 `INSUFFICIENT_MATERIALS` 是同一条原则：**宁可没有，不要编。**

## 二、后端两个只读接口

| 接口 | 返回 | 数据来源 |
|---|---|---|
| `GET /api/v2/agent/profile` | 掌握度、来源标记、画像版本、错题明细、换算规则 | `profiles` + `wrong_book`（按 userId 过滤） |
| `GET /api/v2/agent/knowledge?q=` | 命中片段：文件名、章节、哈希、相似度、正文 | 网关代调 MCP `search_learning_materials` |

### 为什么引用要由网关代调

浏览器不能直连 MCP——那需要 `MCP_API_KEY`，而密钥绝不能下发前端。
网关带着密钥调本机 MCP，只把脱敏结果给页面。

### 需要的环境变量（`gateway.env`）

```bash
MCP_BASE_URL=https://127.0.0.1:8443
MCP_API_KEY=<与平台 MCP 配置里相同的 Key>
MCP_SESSION_REF=sref-demo-0000000000000001
```

缺了会怎样：引用面板显示"检索不可用：MCP_UNCONFIGURED"，对话本身不受影响。

## 三、验收

| # | 操作 | 期望 | 证明 |
|---|---|---|---|
| E1 | 打开页面 | 证据栏顶部出现 3 个掌握度标签 | profile 接口通 |
| E2 | 点「二叉树遍历基础 42」 | 弹窗显示来源、版本、错题、规则 | **数字可追溯** |
| E3 | 问「后序遍历是什么」 | 证据栏出现 `二叉树讲义.pdf` 命中 | 引用可见 |
| E4 | 点开该命中 | 看到章节、哈希、正文 | 引用可核对 |
| E5 | 问一个资料里没有的词（如「傅里叶变换」） | 显示"本次回答没有引用资料" | **没依据不编** |
| E6 | 做一次错题（发"我错了"走 record_wrong_question） | 掌握度标签数字变小，点开的错题记录多一条 | 闭环可见 |

E6 是闭环的关键：**同一个标签，数字变了，且能点开看到为什么变。**

## 四、答辩一句话

> "界面上每个数字都能点开：掌握度能追到规则和错题，引用能追到文件、章节和片段哈希。
> 我们不让模型报数字——它只负责解释这些数字。"
