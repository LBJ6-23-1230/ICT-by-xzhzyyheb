# Web 演示对照赛题要求（现状核对）

> 依据：赛题 2 任务要求里“通过可视化 Demo 页面展示核心功能与交互流程”，
> 以及“应体现 AgentArts 在智能体设计、工具编排、知识接入、多 Agent 协作、效果评估等环节的使用价值”。

## 一、要求逐条对照

| # | 赛题要求 | Demo 里要看见什么 | 现状 | 差什么 |
|---|---|---|---|---|
| 1 | 智能体设计 | 一句话被交给哪个 Agent、为什么是它 | ⚠️ 部分 | 时间线只显示“交给 wf-xxx”，**没有“为什么不是别人”** |
| 2 | 工具编排 | 调了哪些工具、耗时、成功/失败 | ⚠️ 部分 | 工具事件在 SSE 里有，但**页面不一定渲染**（取决于平台是否发 plugin_start/end） |
| 3 | 知识接入 | 上传讲义 → 立刻能用来出题；回答带来源 | ✅ 有 | 引用面板已可点开（文件名/章节/哈希）；上传后立即可检索 |
| 4 | 多 Agent 协作 | 不同意图进不同工作流 | ✅ 有 | 诊断/规划/出题/评估 四条已通；**讲解（wf-tutor）未建** |
| 5 | 效果评估 | 有评测集与数字（准确率/时延/幻觉率） | ❌ **没有** | 需要 S6：20 条用例 + 跑分脚本 + 报告 |
| 6 | 完整闭环（场景→架构→编排→调优→上线） | 材料里讲清过程 | ⚠️ 有素材没整理 | 踩坑记录很多，需要成文 |

## 二、当前 Demo 实际能演什么

```text
顶栏：云端 AgentArts 徽标 + 运行时名 + 学情入口
左栏：对话（用户气泡 / 助手回答 / 每答下方的依据入口与答题卡）
中栏：执行时间线（开始 → 交给 wf-xxx → 结束）
右栏：运行详情（runId / 会话）
右上：📎 上传讲义   📷 拍错题
```

已能演示的六段：

| # | 操作 | 看到什么 | 对应要求 |
|---|---|---|---|
| 1 | 打开页面 | 徽标来自 `/runtime` 接口 | 平台在用（真实） |
| 2 | 问“我哪里薄弱” | 进 wf-diagnosis，回答带掌握度与依据条数 | 4 多 Agent |
| 3 | 问“今晚只有 60 分钟” | 进 wf-planner，任务排满 + 延期带原因 | 4 多 Agent |
| 4 | 拍一张错题 | 识别题干 → 预填 → 发送后讲解 | 3 知识接入 |
| 5 | 出两道题 | 一句引导语 + **答题卡**（点选项） | 1/2/3 |
| 6 | 提交作答 | 得分、逐题对错、正确答案、掌握度变化、是否重排 | 5 的雏形（单轮，不是评测） |

## 三、按评分权重的短板

初赛 **创新性 60% + 应用价值 40%**。

| 短板 | 影响 | 补法 | 成本 |
|---|---|---|---|
| **没有效果评估** | 官方明写要体现，现在 0 | 平台「效果评估」建 20 条用例跑一次 + 本地脚本统计路由准确率/时延 | 半天 |
| 智能体设计不可解释 | 60% 里的“设计思路创新”讲不实 | 时间线加“排除理由”（按工作流名+原话生成一句） | 2 小时 |
| 工具编排看不见 | 评委只能看到工作流名 | 确认并渲染 `plugin_start/plugin_end`（工具名+耗时+成功） | 1–2 小时 |
| 讲解能力缺失 | 拍错题后只能给薄弱点 | wf-diagnosis 加“若是具体题目先讲题”（已在提示词里） | 已改，待验 |
| 闭环只到“交卷” | 错题不入错题本 | 交卷后把错题写进 `wrong_book`（`record_wrong_question` 已有，未接 UI） | 2 小时 |

## 四、建议的 90 秒演示（按评分点组织）

| 时间 | 动作 | 命中的评分点 |
|---|---|---|
| 0:00 | 打开页面，指徽标与运行时名 | 真的在平台跑 |
| 0:10 | “我哪里薄弱” | 多 Agent + 工具编排 |
| 0:25 | “今晚只有 60 分钟” | 多 Agent，且延期有原因 |
| 0:40 | 出两道题 → **点选项提交** | 知识接入 + 交互创新 |
| 1:05 | 看结果卡：❌ 第 1 题，正确答案 C；掌握度 42→38 | **确定性计算**（数字可点开） |
| 1:20 | 再问一次“我哪里薄弱” | 闭环：学情变了 |
| 1:30 | 上传一份新讲义 → 再出题，带“依据：文件名” | 用户能进来 + 依据可追 |

## 五、一句话结论

> **能力已经够演 90 秒，但“可证明”的两块还缺：效果评估的数字、Agent 决策的解释。**
> 这两块加起来约一天工作量，比再加功能划算得多。
